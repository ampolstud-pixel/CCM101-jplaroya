# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions needed to perform their tasks. This helps prevent unauthorized access and limits the damage caused by compromised accounts. Regularly reviewing permissions also helps keep the system secure.

## 2. Attack Surface

The attack surface includes all the points where an attacker might try to access or exploit a system. Open ports, unnecessary services, weak passwords, and outdated software increase security risks. Reducing these risks helps protect the server from possible attacks.

## 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a firewall rule specifically allows the connection. This helps protect the server by blocking unnecessary and unauthorized access. Only required ports and services should be allowed to reduce security risks.
