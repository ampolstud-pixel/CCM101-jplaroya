# Final Reflection – CCM101 Mission 10

This laboratory helped me understand how cloud infrastructure and containerization work together to deploy a web application.

During this activity, I used Oracle VM VirtualBox to run Ubuntu Server. I installed and configured Docker and Docker Compose to deploy WordPress and MySQL in separate containers. I also learned how persistent volumes protect important website and database information even when containers are restarted.

One of the most important parts of this activity was configuring the UFW firewall. I learned that securing a server is necessary to control incoming connections and protect running services.

I also learned how to automate backups using Bash scripting and Cron Jobs. Instead of manually creating backups every time, I configured the system to perform automatic backups every day at 2:00 AM. Testing the backup script helped me understand how database and website files can be protected.

I encountered several errors while editing commands and configuring the backup script. However, troubleshooting each problem helped me improve my Linux command-line skills and understand the importance of correct syntax and file configuration.

Overall, this laboratory improved my knowledge of server administration, Docker, database management, security, and automation. It also taught me the importance of maintaining backups and documenting technical configurations.

This experience gave me a better understanding of how real-world web applications can be deployed and maintained using cloud technologies.
