## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a wide selection of cloud services. These services cover computing, storage, databases, networking, security, analytics, and other areas. Its broad service portfolio supports different types of cloud projects and business requirements.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides strong integration with Microsoft technologies. Azure suits organizations that use Windows Server, Microsoft 365, and Microsoft identity technologies. This integration helps organizations manage Microsoft-based applications and infrastructure.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for artificial intelligence, data analytics, and Kubernetes. Google Kubernetes Engine (GKE) provides a managed environment for deploying and managing containerized applications. Google Cloud also provides services for machine learning and data processing.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a wide range of cloud services. AWS gives users flexibility when building cloud applications and infrastructure. Its services support both small projects and large enterprise systems. AWS also provides different options for computing, storage, databases, networking, security, and application development.
