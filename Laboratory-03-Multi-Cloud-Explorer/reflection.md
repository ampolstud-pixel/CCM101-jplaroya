# Reflection

## 1. Which cloud platform impressed you the most?

During this laboratory activity, Google Cloud Platform impressed me the most. I found its services for artificial intelligence, machine learning, data analytics, and Kubernetes useful for modern cloud applications. These services helped me understand how cloud computing supports projects that require high computing power and large amounts of data.

## 2. What the similarities exist among AWS, Azure, and GCP?

AWS, Microsoft Azure, and GCP provide many similar cloud services. These include virtual machines, storage, databases, networking, and identity management. Each provider also has different strengths. AWS provides a wide range of services. Azure has strong integration with Microsoft technologies. GCP has strong services for data analytics, artificial intelligence, machine learning, and Kubernetes.

## 3. How do business requirements influence cloud platform selection?

Business requirements affect the choice of a cloud platform. A company should consider its budget, existing technologies, scalability needs, security requirements, performance, and business goals. For example, Azure suits an organization that uses Microsoft technologies. GCP suits a company focused on artificial intelligence and data processing.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

Working as a Cloud Solutions Consultant taught me to connect technical decisions with business requirements. I learned that the best cloud solution depends on the client's specific needs. Comparing cloud services also helped me understand how different providers address similar requirements through different technologies.
