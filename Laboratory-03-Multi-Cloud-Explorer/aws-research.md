# AWS Research

 ## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. AWS provides services for computing, storage, databases, networking, security, analytics, and application development.

## Global Infrastructure

AWS uses a global infrastructure made up of Regions and Availability Zones. Organizations can deploy applications in different geographic locations. This setup supports application availability, reliability, and performance.

## Cloud Management Console

The AWS Management Console is a web-based interface for managing AWS services and resources. Users can create, configure, monitor, and manage cloud resources through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers for running applications, websites, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for files, backups, images, videos, and other types of data.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) provides managed relational databases. AWS handles many database management tasks, allowing users to focus on their applications.

### 4. AWS Lambda

AWS Lambda runs code without requiring users to manage servers directly. Developers can use Lambda for applications, APIs, automation, and event-based tasks.

## Three Advantages

AWS provides a wide range of cloud services for different requirements.
AWS resources support scaling based on application demand.
AWS has a global infrastructure with Regions and Availability Zones.

## Typical Enterprise Use Cases

AWS supports many business and enterprise workloads, including:

- Website hosting
- Mobile application hosting
- Data storage
- Database management
- Backup and disaster recovery
- Data analytics
- Application development
- Serverless applications
