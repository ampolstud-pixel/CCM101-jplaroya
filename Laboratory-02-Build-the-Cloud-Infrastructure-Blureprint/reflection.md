# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?
I think compute resources are one of the most important parts of cloud infrastructure. They provide the processing power needed to run applications and services. Without compute resources, applications cannot perform their tasks. During this laboratory, I observed that the KillerCoda environment used an Intel Xeon E312xx CPU with one CPU core. This helped me understand how cloud environments allocate computing resources for users.

## 2. How does Linux support cloud computing?
Linux supports cloud computing by providing a reliable operating system for cloud servers and virtual machines. It also provides command-line tools for checking and managing system resources. During this laboratory, I used Linux commands such as lscpu, free -h, df -h, hostname, and hostname -I to examine the cloud server. Linux makes cloud infrastructure easier to manage and monitor.

## 3. Why is technical documentation important before deploying infrastructure?
Technical documentation is important because it provides a clear record of the infrastructure configuration and design. It helps engineers understand the resources being used and reduces mistakes during deployment. Documentation also helps engineers troubleshoot problems and maintain the infrastructure over time.

## 4. What new skills did you learn during this laboratory activity?
I learned how to investigate a Linux cloud server using terminal commands. I learned how to check CPU, memory, storage, networking, and operating system information. I also learned how to compare services from AWS, Microsoft Azure, and Google Cloud. In addition, I practiced organizing technical information using Markdown and GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?
My GitHub portfolio improved after I added a structured cloud infrastructure laboratory. The project includes technical documentation, infrastructure analysis, cloud provider comparisons, screenshots, and an architecture diagram. This project shows my practical skills in cloud computing and Linux. The organized structure also makes my work easier to review and understand.
