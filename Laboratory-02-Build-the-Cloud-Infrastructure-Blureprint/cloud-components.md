# Cloud Infrastructure Components

## 1. Compute Resources
Compute resources provide the processing power needed to run operating systems, applications, and workloads.

Compute resources are important because cloud applications need processing power to execute programs and services. Cloud providers allow organizations to increase or decrease compute resources depending on their workload.

In the KillerCoda environment, the CPU is used to execute Linux commands, run applications, and perform laboratory activities.

## 2. Storage Resources
Storage resources are used to save operating system files, applications, configurations, and user data.

Cloud storage is important because applications need persistent space to store data. Cloud providers can provide scalable storage without requiring organizations to maintain physical storage hardware.

The KillerCoda Linux environment uses its virtual disk to store the Ubuntu operating system, installed software, and other files required by the laboratory.

## 3. Networking Resources
Networking resources allow computers, applications, and users to communicate with each other and access services.

Networking is important because cloud servers need to communicate with users, other servers, databases, and internet services.

The KillerCoda Linux environment uses network interfaces and IP addresses to communicate with the KillerCoda platform and other network resources.

## 4. Operating System
The operating system manages the computer's hardware and provides an environment where applications and commands can run.

An operating system is important because cloud applications and services need an operating environment to execute. Linux is widely used for cloud servers because it supports many server applications and provides powerful command-line tools.

The Ubuntu operating system allows me to interact with the cloud server through the Linux terminal and perform the commands required for this laboratory.
